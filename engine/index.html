引擎點運作

TX-Oracle v3 將兩個獨立模型喺機率層融合，再加因子修正：

  • LightGBM（lambdarank）——學習每場馬之間嘅相對排序，捕捉複雜非線性關係（場內排序主力）。
  • ELO + 因子模型——馬匹／騎師／練馬師嘅長期實力評分，加檔位、負磅修正。
finalScore = 1500 + ( α·lgb_z + (1−α)·elo_z + factor·0.5 ) × 100
ELO 組合 = 0.7×馬匹ELO + 0.2×騎師ELO + 0.1×練馬師ELO + 檔位 + 負磅

混合權重 α 由後台動態管理，每個賽馬日自動評估模型健康度再決定偏重邊個模型，毋須人手。訓練資料涵蓋 2016 年至今全部香港賽事（8,000+ 場、~98,000 條出賽記錄）。
